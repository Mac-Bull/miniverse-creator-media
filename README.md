# Miniverse Creator Media

Responsive bilingual website for Miniverse Creator Media, a TikTok LIVE creator agency.

## Features

- English and Indonesian language switcher
- Responsive desktop, tablet, and mobile layouts
- Scroll-triggered reveal animations
- Creator services, stories, journey timeline, and application call to action

## Project structure

```text
assets/
  css/       Website styles
  images/    Production website images
  js/        Website interactions and translations
  source/    Original design and editable source files
index.html   Main page
```

Open `index.html` directly in a browser to preview the site.
